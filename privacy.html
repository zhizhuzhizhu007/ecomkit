Privacy Policy

Last Updated: October 2026

1. Overview & Scope

This Privacy Policy explains how information is handled in connection with EcomKit ("we", "us", or "our"), which encompasses:

  1. The EcomKit Canva Application: The design utility running inside the Canva platform.
  2. The EcomKit Website: The static informational site hosted on GitHub Pages (zhizhuzhizhu007.github.io/ecomkit/).

We are committed to operating with transparency. Because EcomKit is an independent utility operating within third-party environments (Canva and GitHub Pages), data handling depends on both our application architecture and the hosting infrastructure of those platforms.

2. The EcomKit Canva Application

2.1 Architecture and Local Generation

EcomKit is built using the Canva Apps SDK. In its current implementation:

  • Local SVG Generation: Dimension line vectors and trust badge assets are generated or loaded locally within the application runtime inside Canva.
  • No Dedicated User Database: EcomKit does not operate a standalone third-party user registration system, login database, or customer profiling infrastructure.
  • Direct Canvas Insertion: Generated vector graphics are inserted directly onto your active Canva design page using official Canva Apps SDK APIs.

2.2 Canva Permissions

The EcomKit Canva application requests the following standard permissions specified in its application manifest:

  • canva:design:content:read: To determine design context and layout support.
  • canva:design:content:write: To insert the generated dimension lines and trust badges onto your active design page.

These permissions are exercised solely to provide the core design features described in our documentation.

2.3 Platform Telemetry & Infrastructure Notice

Important Platform Note:

While EcomKit does not independently run analytics or tracking servers, the application executes within Canva's environment. Canva may collect operational logs, diagnostic metrics, and usage statistics in accordance with Canva's own privacy terms. We encourage users to review Canva's Privacy Policy for platform-level data practices.
